# JA21-DeepML-Motion-Animation-Language-Suite-1.0.0

Study rigs, poses, blends, and retargeting with JA21 DeepML Motion/Animation. This offline language suite combines 10,000 normalized records, 1,000 source programs, a 22-chapter textbook, and teaching materials across 45 topics. Study motion contracts, diagnostics, and provenance while keeping modeled results distinct from native playback evidence.

The JA21 DeepML Motion/Animation Language Suite is an offline research and teaching package for motion-language concepts, including rigs, poses, blends, and retargeting contracts. It helps educators, animation-tool researchers, technical artists, and language implementers study how motion descriptions, diagnostics, and evidence can be organized in a code-first profile.

The suite contains a 10,000-record normalized technical corpus, twenty navigable shards, 1,000 source-faithful .deepml programs, and a 22-chapter textbook. Coverage spans 45 topics and six tiers, with positive, diagnostic, and certification material. A twelve-week curriculum, student workbook, instructor guide, topic atlas, starter project, grammar assets, semantic operators, compiler/runtime contracts, and conformance guidance connect examples to a wider learning path. Offline tools, catalogs, and manifests support search and integrity review.

The audit qualifies generated compiler and runtime labels as modeled evidence and checks schema, policy, source hashes, and master/shard consistency. Native parsing, solving, playback, rendering, and replay are not demonstrated by the supplied package. Complete grammar and runtime implementation remain open, and simulation descriptions must remain distinct from observed physical or display execution.

## Corpora and audit records

The supplied corpus layout is preserved under `payload/`. The `audit/` directory and [AUDIT_AND_UPGRADES.md](AUDIT_AND_UPGRADES.md) record source coverage, release changes, and evidence boundaries.

Historical source archives and source manifests remain provenance records. Current publication file hashes are listed in `PUBLICATION_SHA256.json`; licensing changes are recorded in `PUBLICATION_LICENSE_LEDGER.json`.
