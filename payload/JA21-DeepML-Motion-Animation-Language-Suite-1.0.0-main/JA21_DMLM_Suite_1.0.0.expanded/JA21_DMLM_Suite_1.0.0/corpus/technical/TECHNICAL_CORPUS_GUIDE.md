
# DeepML Motion/Animation Technical Corpus

## Purpose

This directory is the normalized technical heart of the standalone JA21 DeepML Motion/Animation Language Suite. It converts the uploaded 102-document coupling-mechanics wrapper into a clear evidence model without discarding source, AST, semantic, compiler, runtime, validation, provenance, R12, MCRT, or Smithson 8S data.

## Contents

- `deepml_motion_animation_technical_corpus_10000.jsonl.gz` — all 10,000 records.
- `motion_01.jsonl.gz` through `motion_20.jsonl.gz` — twenty 500-record shards.
- `technical_record.schema.json` — normalized record schema.
- `corpus_index.csv` — compact navigation and analysis index.

## Record architecture

Each normalized record separates identity, pedagogy, source, AST, semantics, compiler evidence, runtime evidence, optimization notes, validation, provenance, record-level coupling evidence, and the document-level 8S claim boundary. This separation lets an animator study a readable program while a language implementer can inspect typed status, diagnostics, replay requirements, R12 relations, and MCRT relations.

## Motion evidence discipline

Transforms, skeleton topology, pose state, channels, clips, blend weights, state transitions, inverse-kinematics schedules, retarget maps, root motion, contacts, trajectories, physics coupling, and timeline bindings must remain explicit. Visual plausibility alone does not prove semantic validity or deterministic replay.

## Native-evidence boundary

The corpus models expected compiler and runtime behavior. Native parsing, compilation, animation playback, device execution, and rendered-motion equivalence require a conforming DeepML Motion compiler and runtime, neither of which was supplied with the attachment.
