# DeepML Motion/Animation Student Workbook

Use the 1,000-script catalog to select programs and record every source ID used.

## Exercise 1: The Motion Language as an Evidence-Bearing JA21 Suite

**Primary task:** Build an annotated evidence map for ten foundation programs.

**Evidence to submit:**

- Selected script IDs and paths
- Source and semantic hashes
- Expected compiler/runtime stage
- Observed or modeled result
- R12/MCRT fields affected
- Replay state, tolerance profile, and limitations

**Reflection:** What would make this result reproducible in a second editor, compiler, or runtime?
